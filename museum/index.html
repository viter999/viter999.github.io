QT.2026.01died 31 Aug 2026DEAD

The Gap That Would Not Close

Binance perps vs spot · 82,619 events

The idea
When a perp price breaks away from spot, it snaps back far enough to trade.
Rule set before the data
Gross move of at least 58 bps, the round-trip cost.
Cause of death
It moved +3.78 bps, about 15× too small. The sealed holdout, opened later, showed only +1.23 bps, with a confidence range touching zero.

Its stopping rule closed the whole perp-microstructure direction family. I later reopened it once, for the liquidation-flush test now in storage.

QT.2026.S1confirmed 22 Oct 2026CONFIRMED

How Big Next Week Moves

Binance perps · 1,303 + 847 forecast dates

The idea
A 50/50 blend of the 10-day and 100-day average range predicts next week's move size best.
Rule set before the data
Lowest error, then confirmed on held-out data at z of 2.33 or more.
Result
Confirmed at z 6.47. It predicts how far prices move, not which way. That alone makes no money.
READ THE AUTOPSY >

One test passed. It answers a smaller question: how big will next week's moves be? That helps size positions so each trade risks the same amount.

It says nothing about direction, so on its own it makes no money. It is here because a museum of failure should also show what survived the same rules.

Why keep a museum of failure?

A failed test written down can't come back later dressed as a new idea. Publishing the deaths also shows what a fair test looks like: the rule comes first, the data gets one look, and the result stands.
